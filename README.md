# Agencia

Agencia de desarrollo web y software.

Este repositorio centraliza la información del proyecto: identidad de marca, servicios, precios, posicionamiento, estrategia comercial, decisiones, ideas, tareas e historial.

## Estado del proyecto

La agencia se define como una **agencia de desarrollo web y software**. La documentación debe distinguir entre decisiones confirmadas, propuestas, ideas, elementos descartados y pendientes.

## Documentación

La documentación detallada se organizará progresivamente en `docs/`.

## Contexto para asistentes

Antes de proponer cambios o tomar decisiones sobre la agencia, consulta primero `CONTEXT.md` y los documentos relevantes de `docs/`. No presentes ideas o propuestas como decisiones aprobadas.

## Mantenimiento

Actualizar este repositorio cuando se tomen decisiones o se produzca información relevante sobre la agencia.
