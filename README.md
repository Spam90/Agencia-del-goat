# Agencia

Agencia de desarrollo web y software.

Este repositorio es la fuente central de contexto del proyecto. Conserva decisiones, identidad de marca, estrategia, servicios, precios, ideas, descartes, tareas y glosario.

## Empieza aquí

1. [Contexto operativo](CONTEXT.md) — resumen para asistentes y colaboradores.
2. [Registro de decisiones](docs/decisiones.md) — qué está confirmado, descartado o en exploración.
3. [Identidad visual](docs/identidad-visual.md) — paleta, tipografías, logo y movimiento.
4. [Identidad verbal](docs/identidad-verbal.md) — tono y trabajo pendiente.
5. [Posicionamiento](docs/posicionamiento.md) — propuesta de valor y diferenciación.
6. [Servicios y precios](docs/servicios-y-precios.md) — pendiente de transcribir desde el chat original.
7. [Ideas y propuestas](docs/ideas-y-propuestas.md) — exploraciones aún no aprobadas.
8. [Tareas pendientes](docs/tareas-pendientes.md) — backlog del proyecto.
9. [Glosario](docs/glosario.md) — términos consultados.

## Reglas de mantenimiento

- Consultar `CONTEXT.md` antes de continuar el trabajo.
- Distinguir decisiones confirmadas, propuestas, ideas, descartes y pendientes.
- No inventar datos que no estén documentados.
- Actualizar este repositorio cuando se tome una decisión o surja información relevante.
- Mantener el contexto operativo breve y enlazar los detalles desde `docs/`.
