## Categoría
Agencia de desarrollo web y software.

## Trabajo pendiente
1. Definir clientes objetivo prioritarios.
2. Identificar problemas costosos o frecuentes que esos clientes necesitan resolver.
3. Especificar qué soluciones desarrolla la agencia y qué resultados puede demostrar.
4. Identificar diferenciadores reales (proceso, especialización, velocidad, calidad, soporte, integración u otros) y validar cuáles son ciertos.
5. Formular una propuesta de valor clara y comprobable.
6. Traducir el posicionamiento a la web, propuestas comerciales y comunicación.

## Criterio
No usar frases genéricas como “soluciones innovadoras” como único diferenciador. Toda afirmación comercial debe poder explicarse y, cuando corresponda, demostrarse.

## Restricción
No redefinir el tipo de empresa: ya está establecido que es una agencia de desarrollo web y software.
