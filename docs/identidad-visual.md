# Identidad visual

**Estado:** decisiones base confirmadas; manual ampliado pendiente.

## Dirección creativa
Minimalismo tecnológico, con una personalidad innovadora y profesional. La identidad debe sentirse tecnológica y sofisticada sin recurrir a clichés visuales ni a efectos excesivos.

## Paleta cromática

| Uso | Color | Hex |
|---|---|---|
| Fondo oscuro principal | Negro | `#090B10` |
| Acento principal | Azul eléctrico | `#2563EB` |
| Contraste/fondo claro | Blanco | `#FFFFFF` |
| Texto secundario | Gris azulado | `#94A3B8` |
| Acento secundario | Azul claro | `#60A5FA` |

El azul se reserva principalmente para acciones, enlaces y destacados. Evitar introducir colores adicionales sin una razón funcional.

## Tipografía
- **Sora:** Bold, Semibold y Medium para títulos.
- **Inter:** Regular, Medium y Semibold para párrafos, botones y textos de interfaz.

## Logo
- Deben contemplarse las dos versiones: símbolo acompañado del nombre y símbolo independiente.
- No deformar, estirar ni alterar las proporciones del logo.
- Se exploró un símbolo con sensación de remolino. No hay constancia suficiente para afirmar que el diseño final esté aprobado.
- Una propuesta de H blanca sobre fondo negro fue rechazada por el usuario: le pareció demasiado sencilla y pidió un diferenciador; posteriormente indicó que no quería un logo basado en una letra.

## Movimiento e interacción
Se prefieren animaciones dinámicas:
- Transiciones fluidas.
- Apariciones progresivas de elementos.
- Efectos hover.
- Formas geométricas y microinteracciones.

Las animaciones deben reforzar jerarquía y respuesta de interfaz, no distraer ni perjudicar tiempos de carga, accesibilidad o rendimiento.

## Principios de aplicación
- Espacios amplios.
- Consistencia tipográfica.
- Contraste y legibilidad.
- Pocos colores y efectos.
- Prioridad al rendimiento.
- Mantener una composición limpia y reconocible.
