# Glosario

Términos consultados durante el trabajo de la agencia.

- **SEO (Search Engine Optimization):** optimización de un sitio para mejorar su visibilidad en los resultados orgánicos de motores de búsqueda.
- **Google Search Console:** herramienta de Google para supervisar cómo aparece un sitio en la Búsqueda de Google, revisar rendimiento e identificar problemas de indexación. Complementa el SEO; no lo reemplaza.
- **Landing page:** página diseñada para una campaña u objetivo de conversión concreto, normalmente con una llamada a la acción principal.
- **Catálogo digital:** presentación organizada de productos o servicios para que el visitante los explore. Puede incluir llamadas a la acción, pero su propósito principal es mostrar una oferta.
- **A/B testing:** experimento que compara dos variantes (A y B) para medir cuál obtiene mejores resultados según una métrica definida.
